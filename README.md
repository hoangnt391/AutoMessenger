# AutoMessenger

Ứng dụng hỗ trợ trả lời tin nhắn bằng AI trên Android.

## 📥 Tải ứng dụng

### APK mới nhất
Sau khi GitHub Actions build thành công, APK sẽ được đăng trong **Releases** của repository.

👉 **[Tải AutoMessenger APK](https://github.com/hoangnt391/AutoMessenger/releases/latest)**

Nếu chưa có bản Release, bạn có thể vào **Actions → Android Build → Artifacts** để tải bản APK của build mới nhất.

👉 **[Mở GitHub Actions](https://github.com/hoangnt391/AutoMessenger/actions/workflows/android.yml)**

## ✨ Tính năng

- Trả lời tin nhắn tự động bằng AI.
- Nhận diện ô nhập tin nhắn như “Tin nhắn”, “Nhắn tin”, “Nhập tin nhắn”.
- Khung AI riêng để nhập/dán câu hỏi và tạo câu trả lời.
- Có thể sao chép **câu hỏi** và **câu trả lời**.
- Có thể đưa câu trả lời vào ô chat bên ứng dụng nhắn tin để người dùng kiểm tra và gửi.
- Hỗ trợ bật/tắt chế độ tự động trả lời.
